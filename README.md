# 🛒 Smart Shopping Assistant

Smart Shopping Assistant is a smart shopping platform that helps users find suitable products based on their requirements and budget. It provides an easy shopping experience through web and mobile applications.

## ✨ Features
- Smart product search using natural language.
- Budget-based product filtering.
- Top 3 product recommendations.
- Product catalog with prices.
- Add, remove, and update cart items.
- Automatic total price calculation.
- Razorpay Test Mode payment simulation.
- Flutter mobile application.

## 🛠️ Technologies Used

**Web:** HTML, CSS, JavaScript

**Mobile:** Flutter, Dart

**Tools:** VS Code, Android Studio, GitHub

## 📱 Flutter App

The Flutter application provides a mobile-friendly interface for browsing products, searching, filtering by budget, and managing the shopping cart.

## ⚙️ How to Run

**Web Application:** Open `index.html` in your browser.

**Flutter Application:**
```bash
cd flutter_app
flutter pub get
flutter run
```
